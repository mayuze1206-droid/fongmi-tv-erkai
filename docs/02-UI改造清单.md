# 双端 UI 改造清单（leanback + mobile）

> 基于 FongMi/TV 真实目录结构（2026-11 核实）。App 采用 Android sourceSet 分端：
> - `app/src/leanback/` → 电视端（遥控器 D-pad，10-foot UI）
> - `app/src/mobile/` → 手机端（触屏）
> - `app/src/main/` → 两端共享的业务逻辑、数据模型、网络层
>
> **改 UI 的铁律：只动 leanback / mobile 的 UI 层，别碰 main 里的业务核心**，否则你的片源 Spider 会被误伤。

---

## 0. 改造分层（按改动量从小到大）

| 层级 | 改什么 | 难度 | 影响 |
|---|---|---|---|
| L1 品牌化 | 应用名、图标、主题色、启动图 | 低 | 不改任何逻辑 |
| L2 视觉风格 | 卡片圆角/比例、首页布局、深色配色 | 中 | 改 Adapter / 自定义 View |
| L3 交互与页面 | 新增页面、改导航、加二维码/遥控入口 | 高 | 改 Activity / Fragment |

建议先做 L1 快速看到效果，再按需要推进 L2/L3。

---

## 1. L1 品牌化（两端都要改）

| 目标 | 文件位置（两端各自） | 改法 |
|---|---|---|
| 应用名称 | `app/src/{leanback\|mobile}/res/values/strings.xml` | 改 `app_name` 的值 |
| 应用图标 | `app/src/{端}/res/mipmap-*/ic_launcher*` | 替换各dpi的图标资源（保持文件名不变） |
| 主题色 | `app/src/{端}/res/values/colors.xml` | 改主色/强调色/背景色的色值 |
| 主题样式 | `app/src/{端}/res/values/styles.xml` 或 `themes.xml` | 改 `AppTheme` 继承项与配色引用 |
| 启动图 | `app/src/{端}/res/drawable/` 下的 splash | 替换启动页图片 |

> 注意：`{端}` 表示 leanback 和 mobile 两个目录**都要各改一遍**；若某些资源在 `main` 里共享，则只改 main 一次即可 —— 先用 Glob 确认资源实际所在 sourceSet。

## 2. L2 视觉风格

### 电视端（leanback）

真实文件位于 `app/src/leanback/java/com/fongmi/android/tv/ui/`：

| 目标 | 文件 | 改法 |
|---|---|---|
| 首页卡片样式 | `ui/adapter/*.Adapter.java`、`ui/base/BaseVodHolder.java` | 卡片图片比例、圆角、焦点高亮色 |
| 首页板块布局 | `ui/activity/HomeActivity.java`、`ui/fragment/TypeFragment.java` | 板块顺序、每行条目数 |
| 详情页 | `ui/activity/VodActivity.java` | 详情头图、简介区、选集区布局 |
| 播放器控制栏 | `ui/custom/LeanbackTimeBar.java`、`ui/activity/VideoActivity.java` | 进度条样式、控制按钮 |
| 自定义视图 | `ui/custom/Custom*.java` | 标题栏、Tab、键盘等视觉 |
| 焦点/选择器 | `ui/custom/CustomSelector.java` | 焦点框颜色、动效（遥控器体验核心） |

> 提示：卡片的图片比例也受 Spider 返回的 `style` 字段影响（见 `docs/01` 的 `style.type/ratio`）。你可以**只改 Spider 的 style 返回值**来调整海报是竖版(0.75)还是横版(1.78)，无需改 Java 代码——这是最省事的视觉调整入口。

### 手机端（mobile）

| 目标 | 文件（在 `app/src/mobile/` 下，结构类比 leanback） | 改法 |
|---|---|---|
| 首页 | `ui/activity/MainActivity.java` / `Home*.java` | 底部导航、首页 Tab |
| 列表卡片 | `ui/adapter/*Adapter.java` | 卡片布局、瀑布流列数 |
| 详情 | `VodActivity.java` | 详情页布局 |
| 播放 | `VideoActivity.java` | 播放器控制栏（触屏手势） |

> mobile 的确切文件名需在拉下仓库后用 `Glob` 确认（如 `app/src/mobile/**/*Activity.java`），本清单给出的是改造入口与命名规律，避免误导。

## 3. L3 交互与页面（按需）

| 需求 | 涉及 |
|---|---|
| 加「手机扫码遥控」入口文案 | leanback 的 `SettingActivity.java` + 对应布局 xml |
| 改搜索页 | `ui/activity/SearchActivity.java`、`ui/custom/CustomSearchView.java` |
| 加自定义设置项 | `Setting*.Activity.java` + `res/xml/` 下的偏好设置 |
| 改直播 tab | `LiveActivity.java`、`ui/adapter/LiveAdapter.java` |

## 4. 双端 UI 一致性建议

- **共享字符串与色值**：能放 `app/src/main/res/values/` 的就放 main，减少两端重复改。
- **差异只留在 sourceSet**：只有「遥控器焦点」vs「触屏手势」这类本质差异才分端实现。
- **卡片 style 由 Spider 统一控制**：海报比例在 Spider 里返回，两端自动一致，避免改两处 Java。

## 5. 改造工作流（遵守增量原则）

1. 先只改一个文件（如 `strings.xml` 的 app_name），打包验证。
2. 每改一处记录 diff，不要全量覆盖原文件。
3. 改完跑一遍 `grep` 确认没有残留的旧品牌字符串。
4. 两端分别打包，盒子用 `adb install`，手机直接安装，各自实测。
