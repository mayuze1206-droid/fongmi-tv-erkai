# 现成接口接入指南（点播 + 直播）

> 用社区公开接口，零代码接入 FongMi/TV。本文解决：怎么导入、怎么换源、怎么判断线路快慢、直播怎么配。

---

## 1. 三种导入方式（从省事到可控）

### 方式 A：直接贴订阅地址（最省事）
App → 设置 → 配置地址 → 直接填入现成订阅 URL：
```
https://cdn.jsdelivr.net/gh/liu673cn/box@main/m.json
```
确定后 App 自动加载里面所有站点。**缺点**：完全依赖对方更新，你改不了。

### 方式 B：用我给你的配置文件（推荐，点播+直播一次配好）
把 `config/现成接口配置.json` 放到手机/盒子能访问的路径（或传到一个你能控制的 URL，如 GitHub Gist / 自己的服务器），然后在 App 里填这个文件的地址。
- 文件里用 `urls` 引了 3 个点播订阅 + 2 个直播源 + EPG。
- 你想增删源，改这个 JSON 就行，不用动 App 代码。

### 方式 C：只接一个接口（最可控）
用 `config/单站点模板.json`，把 `sites[].api` 换成你的采集接口地址：
- 苹果CMS/采集站返回 **JSON** → `type: 1`
- 返回 **XML** → `type: 0`
- 带分类筛选的扩展 JSON → `type: 4`
填完即可，无需爬虫。

## 3. 关于"秒播不卡"——怎么判断和换线路

没有任何源能保证 100% 秒播，卡不卡取决于三件事：采集站线路质量 + 你的运营商 + 时段。实操方法：

1. **用多仓订阅**：线路多，卡了在 App 里切换站点/线路（设置里有"站点"切换）。
2. **测速选线**：打开影片 → 播放源列表 → 逐个试，选响应快的线路；Selene-TV 这类客户端有一键测速，FongMi 里靠手动切。
3. **看编码格式**：优先选 H.264 的线路，盒子的硬件解码兼容性最好；H.265/4K 对老盒子压力大。
4. **换 DNS**：配置里已带 DoH（阿里/腾讯），能缓解部分域名劫持导致的卡顿。
5. **时段规避**：晚高峰（20:00-23:00）采集站压力大，容易卡，可换冷门线路。

如果某站点长期卡，直接在配置 JSON 里删掉它，或换新接口地址。

## 4. 直播配置说明

`lives` 数组里每个对象：
- `name`：直播配置名（App 里显示）
- `url`：直播列表地址，支持三种格式：
  - **M3U**（如 iptv.org）— 字段最全，推荐
  - **TXT**（如 vbskycn）— 传统格式，`频道名,地址` 每行一条
  - **JSON** — 分组/频道结构
- `epg`：节目单 URL，可留空

直播列表内容由源维护，频道数量/可用性随时变化，**建议定期更新订阅地址**。iptv.org 的 m3u 是自动抓取+校验的，相对可靠。

## 5. 关于"自己能爬取"

社区配置里的 `spider: "./custom_spider.jar"` 就是爬虫——App 加载这个 JAR 后，会按内置规则从采集站爬取分类、列表、选集和播放地址。这是 **type=3 Spider** 机制。

对你来说：
- **现状（推荐）**：导入现成订阅，爬虫 JAR 随配置自动加载并工作，你什么都不用写。
- **将来（可选）**：如果某采集站没有现成接口，想自己爬，就回到 `spider/spider.js` 那套 QuickJS 方案，针对该站写解析。但那是进阶需求，当前用现成源不需要。
